# Project Description: SHRED

SHRED is an offline, native Android media cleaner app built with Kotlin, Jetpack Compose, and Android Architecture Components.

## Core Value Proposition
Traditional gallery cleaners are cluttered and struggle to find media scattered in non-indexed directories or messaging app silos. SHRED combines an unrestricted filesystem crawler with an intuitive Tinder-style card deck and a stark monochrome brutalist industrial design.

## Target Audience & Usage
Designed for power users running Android 14+ who want fast, satisfying, and granular control over their on-device photo, video, and audio clutter.
